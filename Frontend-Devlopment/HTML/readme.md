## Example

A basic semantic HTML page:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Web Page</title>
</head>

<body>

    <header>
        <h1>My Website</h1>

        <nav>
            <a href="#">Home</a>
            <a href="#">About</a>
            <a href="#">Contact</a>
        </nav>
    </header>

    <main>
        <section>
            <h2>About Me</h2>
            <p>
                I'm learning frontend development and building my
                fundamentals one concept at a time.
            </p>
        </section>
    </main>

    <footer>
        <p>© 2026 My Website</p>
    </footer>

</body>
</html>
```
